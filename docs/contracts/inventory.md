# Инвентарь исследовательских контрактов

61 GET из восьми спецификаций — охват снимка, не полный API и не серверный контракт. Вызовы API не выполнялись. `2XX`, `required: false`, media types и иллюстративные схемы не являются наблюдением сервера. CLI не проверяет эти контракты.

## Источники и снимок

[Машиночитаемый снимок](inventory.yaml) содержит все параметры, исходные схемы и ограничения, статусы, media types, подписи SDK, несопоставленные параметры и источники на уровне операции. `spec` — OpenAPI, `research` — отчёт исследования, `sdk` — текущий Python-код; `synthetic-test` — только сериализация в локальном mock; `unknown` — поведение сервера. Схемы безопасности спецификации содержат query `key`; SDK добавляет его транспортом, а не аргументом метода. Отсутствие поля в исходном mapping отличается от `false` и `null`; обязательность на сервере неизвестна. Сопоставление `[]` → `_list` показано в YAML. `scoring.score.balance_fields` — дополнительный SDK-параметр для семейства `bNNNN`, не отдельный параметр OpenAPI; требует проверки у поставщика.

Нормализация `schema-graph-v2`: узел с `$ref` содержит отдельно `fields` (все исходные поля) и `target` (раскрытый граф в `value` либо указатель активной ссылки в `cycle`); это исключает коллизии со служебными ключами. Рекурсивно раскрываются локальные JSON Pointer `$ref`, циклы обозначаются указателем активной ссылки. Mapping сортируется, массивы сохраняют порядок, JSON UTF-8 с сортировкой и компактными разделителями хешируется SHA-256. Алиасы YAML раскрывает загрузчик. Исходная схема и указатель доступны в снимке и OpenAPI; digest сравнивается с текущим полным достижимым графом. Внешняя или неразрешённая ссылка — ошибка. Изменение алгоритма требует явного обновления версии и снимка. Digest не подтверждает сервер.

## Матрица свидетельств POST — отдельно от GET-снимка

33 кандидата — не рабочие вызовы и не проверка сервера. [ФНС RESEARCH](../swagger/fns/RESEARCH.md) описывает 24 кандидата, [Банки RESEARCH](../swagger/banks/RESEARCH.md) — девять. В соответствующих OpenAPI каждый `x-post-contract` — исследовательские метаданные с `sdk-ready: false`, не исполнимая операция POST. Поля внутри расширения, включая иллюстративные параметры Банков, не устанавливают wire-контракт.

Tavily — дополнительное свидетельство публичной справки, не наблюдение сервера: запуск researcher завершился `failed`, отдельная автоматическая проверка цитат недоступна, кириллица извлечённой банковской страницы повреждена. Русские имена полей и точные формулировки по этому извлечению восстанавливать нельзя. Исходные сохранённые рендеры RESEARCH недоступны.

До подтверждения поставщиком для каждого POST пути, расположения ключа и параметров, сериализации и кодирования, обязательности, типов, заголовков, статусов, success/error/no-data, бинарных ответов и семантики рабочий POST не включать. Идемпотентность, стоимость и безопасность повторов также не подтверждены; retry/cache POST не включать. Живые вызовы требуют отдельного разрешения.

## Локальные наблюдения сериализации

`rosstat.multbalance` и `fns.multcheck` передают скалярную и списочную формы
совместно, если обе заданы; пустой список не добавляет параметров, повторы и
порядок значений сохраняются. Это поведение SDK, не подтверждение допустимости
сочетания сервером: документация методов называет формы альтернативными. Какие
сочетания и пустые значения принимает сервер, остаётся открытым вопросом.
Prism-инвентарь объединяет параметры уровня пути и операции с приоритетом
операции по паре `(name, in)`; синтетические ответы не подтверждают MIME или
семантику реального поставщика.
