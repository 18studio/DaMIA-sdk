# Контракт ответов и ошибок SDK

Этот документ описывает текущее поведение SDK, а не подтверждённую схему поставщика. Все примеры и тестовые данные синтетические. HTTP 2xx означает только транспортный успех: SDK не определяет бизнес-ошибку по содержимому; форматы и семантика поставщиком не подтверждены (см. [инвентаризацию](inventory.md)).

Любой статус 200–299 возвращает `HttpResponse`, включая 204; разбор JSON отложен до `json()` или `data`. `json()` разбирает тело независимо от MIME и строго отклоняет некорректный JSON, NaN, Infinity и числа с переполнением float. Пустой JSON, в том числе 204 с JSON MIME, вызывает `DamiaResponseError` при разборе, не при запросе. `data` распознаёт `application/json` и MIME с суффиксом `+json`, независимо от регистра и параметров; `text/*` декодируется UTF-8 с заменой ошибок, прочие или отсутствующие MIME возвращают bytes. JSON не определяется по содержимому.

Тело не включено в `repr(HttpResponse)`, но `content_type` — недоверенный заголовок и **включён** в repr. Не считайте этот repr безопасным для логирования. Например, синтетический `HttpResponse(200, "application/json; marker=synthetic-secret", b"{}")` раскрывает marker в repr.

Не-2xx вызывает `DamiaHTTPError` со статусом и нормализованным `retry_after`; 429 вызывает подкласс `DamiaRateLimitError`. Тело, URL и произвольные заголовки ошибки не сохраняются. Ошибки JSON и HTTPX не привязываются как внутренние исключения SDK; однако активное внешнее исключение вызывающего кода может стать `__context__` и содержать секреты. Вызывающий код отвечает за безопасную обработку цепочек исключений и пользовательских callbacks.

Повторы и кеш по умолчанию выключены и требуют разрешения операции; для кеша обязателен пользовательский `cache_validator`. Кешируются только успешные `application/json` ответы, принятые validator; cache hit повторно проверяется для каждого получателя. `+json`, binary и HTTP-ошибки не сохраняются. Ошибки отложенного разбора JSON автоматически не повторяются. Дополнительные бизнес-валидаторы, метаданные ошибок и расширение MIME кеша не внедрены: требуются отдельные решения и подтверждение поставщика.
