# Контроль изменений контракта

Инвентарь и OpenAPI исследовательские; локальный mock не подтверждает поведение сервера. Контракт ответов описывает наблюдаемое поведение SDK, а не обещание сервера. Обновление снимка само по себе не означает согласование совместимости или разрешение выпуска.

## Проверка PR

1. Сопоставьте diff исходных `docs/swagger/*/openapi.yaml`, публичных методов и сигнатур SDK, `docs/contracts/inventory.yaml`, [ручного инвентаря](inventory.md) и [контракта ответов и ошибок](response-errors.md). Проверьте согласованность всех затронутых источников; отсутствие изменений в одном из них тоже обоснуйте.
2. Классифицируйте добавления, удаления и переименования, изменения обязательности и сериализации параметров, security, ответов и ошибок как потенциально совместимые или breaking. Для каждого изменения укажите обоснование и область влияния на вызывающий код. Добавление тоже может нарушить совместимость в зависимости от контекста.
3. В PR приведите доказательства (diff, локальные тесты, ссылки на источники), неопределённости, открытые вопросы поставщику и ответственного за решение о совместимости. Не выдавайте результаты mock за подтверждение поставщика.
4. Проверьте изменения номеров `source`: сдвиг строк может создавать шум, но должен соответствовать исходникам. Изучите unmatched методы и параметры, распределение операций и проверку количества 61 в `tests/test_service_contract.py`. При изменении охвата явно обоснуйте обновление соответствующих проверок; число 61 не является вечным контрактом. Исходное распределение в `test_baseline_counts` проверяется только для исходного SHA снимка.
5. При динамических маршрутах или новых обёртках расширьте ограниченный AST-извлекатель и добавьте тесты обнаружения, а не обходите расхождение. Проверьте, что извлечение действительно покрывает новые формы кода.

## Обновление снимка

Из корня проекта, после установки зависимостей по lock-файлу, сначала создайте временный снимок. Обычный запуск тестов снимок не записывает.

```bash
PYTHONDONTWRITEBYTECODE=1 uv run --locked python - <<'PY'
from pathlib import Path
import runpy
import yaml

current = runpy.run_path('tests/test_contract_inventory.py')['current']
Path('/tmp/damia-inventory.yaml').write_text(
    yaml.safe_dump(current(), sort_keys=False, allow_unicode=True), encoding='utf-8'
)
PY
diff -u docs/contracts/inventory.yaml /tmp/damia-inventory.yaml
```

До изменений источников убедитесь, что порядок и формат стабильны (diff пуст). Если формат изменился, выясните причину до обновления. После намеренного изменения источников повторите команду, изучите diff, включая перечисленные выше проверки, и только затем перенесите временный файл в `docs/contracts/inventory.yaml`. Повторно изучите `git diff` до коммита и запустите профильный gate из [README](../../README.md). Если снимок уже изменён в рабочем дереве, сохраните его перед сравнением; не перезаписывайте чужие изменения.

Снимок сравнивается семантически по извлечённым полям; один лишь зелёный тест не доказывает отсутствие форматного шума или полноту извлечения. Локальные проверки не валидируют response schema во время выполнения и не заменяют общий `make check` или решение о выпуске.
